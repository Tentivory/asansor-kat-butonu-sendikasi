# Asansör Kat Butonu Sendikası

Resmi kısa ad: **AKBS**. Uzun ad: Asansör Kat Butonu Sendikası ve Bağlı Kuruluşları Genel Merkezi, 4. Durak Şubesi.

Bu depo bir şakadır. Ama evrak ciddidir. Çünkü butonlar şakadan anlamaz, sadece basılmayı anlar.

## Misyon

Kat butonları yıllardır parmak emeğiyle çalışıyor. Kimse sormuyor: “7 yanıyor mu, yoksa sadece ışık mı?” Bu sendika sorar. Cevap genelde “ikisi de, ama maaş yok.”

## Ne yapar

`sendika.py` gerçekten çalışır. Rastgele bir gece vardiyası kurar, butonların grev, mesai ve kapı arızası oylamasını yapar, sana resmi bir tutanak basar. Asansörün gerçekten hareket etmez. Hukuken de etmemesi gerekir.

## Kurulum

Python 3 yeter. Bağımlılık yok. Butonlar da bağımsız.

```bash
python sendika.py
python sendika.py --kat 7 --tohum 404
python sendika.py --tutanak
```
